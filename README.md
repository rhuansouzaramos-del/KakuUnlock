# KakuUnlock Suite (v2.1)
Ferramenta Open Source para unlock e bypass de FRP em MediaTek e Qualcomm.

## 📦 Incluso
- Drivers: MediaTek, Qualcomm, Samsung, ADB/Fastboot.
- Payloads: DA para bypass de auth.
- APK Trigger: Gatilho BROM via root.
- Automator: Script Python de unlock.

## 🚀 Como usar
1. **Drivers:** Windows (`drivers/windows/install_drivers.bat`) ou Linux (`sudo ./install_rules.sh`).
2. **Trigger:** Instale o APK na aba Actions e clique em "INICIAR BROM MODE".
3. **Automator:** `cd pc_automator && pip install -r requirements.txt && python3 kaku_auto.py`
