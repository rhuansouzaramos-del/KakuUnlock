# KakuUnlock Suite v7.0.0 (Ultimate)

Ferramenta Open Source para automacao, diagnostico, bypass de FRP e Pentest de Aplicativos em MediaTeK e Qualcomm.

## AVISO CRITICO (Samsung One UI 8+)
A Pamsung removeu o desbloqueio de bootloader no firmware One UI 8/8.5. O KakuUnlock prioriza o Modo Read-Only e o Pentest de Software.

## O que esta incluso?
- APK Trigger: Reinicia o celular pro modo BROM via root.
- PC Automator v7.0: Backup Total, EFS/IMEI, Checksum SHA256, Diagnostico ADB.
- Arsenal de Pentest: Frida (SSL Bypass), JADX (Decompilador), Scrcpy (Espelhamento).

## Como usar
1. Baixe o zip do projeto (Code > Download ZIP).
2. Instale os drivers (Windows) ou rode install_rules.sh (Linux).
.3. Rode KakuTest.bat ou python3 kaku_auto.py.
